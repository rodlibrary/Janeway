# Rod Library theme mockups

Screenshots of Janeway's public pages with the Rod Library styling and footer from PR #1
(`src/static/common/css/rodlibrary.css` and `src/templates/common/elements/rodlibrary_footer.html`).
Each page is shown in all three built-in themes, so you can compare them and pick one.

## What to review

- Header and navigation colours (Panther Purple `#500778`, Goldenrod `#FFB500` accents)
- Footer: `#2E1A47` background, white text, `#FFB500` links, self-hosted UNI logo
- Headings, body text, links and buttons
- Mobile layout (journal homepage and article page)

## How these were made

Captured from a local Janeway install with invented sample content (the *Iowa Journal of Scholarship*,
four articles, one issue and one news item) at 1440px desktop and 390px mobile widths.
Things that will look different on the live site:

- **Logos and cover images**: the press logo, journal logo and journal cover haven't been uploaded,
  so the default Janeway logo, sample banner image or alt text appear instead.
- **Fonts**: Proxima Nova and Blacker Pro need UNI's Adobe Fonts kit, so fallback fonts are shown.
- **Icons**: some Material theme icons come from Google Fonts, which couldn't load during capture.
